# Digital Library and Knowledge Repository

A web-based platform built on WordPress to solve the problem of accessing, organizing, and managing institutional learning resources and academic research.

## 📌 Project Overview
* **Domain:** Knowledge Management
* **Platform:** WordPress CMS
* **Team Size:** 5 Members (Iconic University)
* **Project Supervisor:** Kabiru Abdullahi

---

## 🚀 Core Features & Module Allocation
* **E-book Management:** Centralized cataloging, categorization, and digital reading/download management for course textbooks and guides.
* **Research Repository:** Dedicated archive for faculty and student research papers, theses, and journals with searchable metadata.
* **Advanced Search Functionality:** Fast, filterable lookup allowing users to query resources by title, author, category, or keyword.
* **User Access Control:** Role-based permissions matrix securing system access across five core WordPress levels:
  * *Administrator* (System management and site configuration)
  * *Editor* (Content approval and global repository management)
  * *Author* (Direct publishing of individual research and books)
  * *Contributor* (Draft submissions requiring review)
  * *Subscriber* (General reading and search access)
